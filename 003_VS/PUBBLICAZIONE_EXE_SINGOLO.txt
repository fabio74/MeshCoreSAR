MESHCORE TRACKER - EXE SINGOLO WINDOWS x64
===========================================

Metodo consigliato
------------------
1. Chiudere l'app MeshCore Tracker se in esecuzione.
2. Prima della pubblicazione, se si vuole usare il GeoTIFF offline senza Internet,
   eseguire PREPARA_MAPPA_OFFLINE_WINDOWS.ps1 una volta mentre il PC e' online.
3. Fare doppio clic su:

   PUBBLICA_EXE_SINGOLO_WINDOWS.bat

4. Al termine il file da distribuire si trova in:

   DIST_EXE\MeshCoreTracker.exe

Copiare sul portatile operativo SOLO questo file EXE.

La pubblicazione usa:
- Windows x64
- Release
- WindowsPackageType=None (unpackaged)
- .NET self-contained
- Windows App SDK self-contained
- PublishSingleFile=true
- IncludeAllContentForSelfExtract=true

IMPORTANTE
----------
Il singolo EXE MAUI/WinUI non e' un eseguibile "zero extraction".
Al primo avvio Windows estrae automaticamente le dipendenze incluse in una
cartella temporanea. Per l'utente rimane comunque un unico file da copiare.

WEBVIEW2
--------
MeshCore Tracker usa WebView2 per la mappa. WebView2 e' normalmente gia'
presente su Windows 11 e sulla maggior parte dei Windows 10 aggiornati.
Su un PC Windows 10/Server/LTSC completamente offline e non aggiornato potrebbe
essere necessario installare una volta il WebView2 Runtime x64.
